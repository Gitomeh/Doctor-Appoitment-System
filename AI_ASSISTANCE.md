# AI Assistance Report

## Project

Doctor Appointment Booking System

## How AI Assisted

AI was used as a development assistant throughout the project.

It helped me:

- Design the application architecture.
- Generate React components.
- Build Express REST APIs.
- Create MongoDB models.
- Implement JWT authentication.
- Configure Nodemailer for email notifications.
- Generate Tailwind CSS layouts.
- Debug frontend and backend issues.
- Improve project documentation.
- Suggest best practices for code organization and security.

## My Role

I reviewed every AI-generated response before using it. I modified, tested, and integrated the code manually to ensure it met the project requirements and worked correctly.

AI accelerated development but did not replace my understanding or decision-making during implementation.
